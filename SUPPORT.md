# Support

Duc's Table is a community-maintained open-source project. Support is public and best-effort; there is no private support channel or response-time SLA.

## Usage and design questions

Use [GitHub Discussions](https://github.com/antonioducs/ducs-table/discussions) for setup help, SQL and workflow questions, ideas, and early feature proposals. Include the Duc's Table version, macOS version and architecture, what you are trying to accomplish, and what you have already tried.

Before posting, review the [README](README.md), [development guide](docs/development.md), and existing discussions. Do not include real datasets, credentials, connection URIs, private paths, or unsanitized logs.

## Reproducible bugs

Use [GitHub Issues](https://github.com/antonioducs/ducs-table/issues) for a concrete product defect that can be reproduced. Please include:

- the affected release or commit, macOS version, and architecture;
- minimal reproduction steps using synthetic data or an isolated read-only fixture;
- expected and observed behavior;
- whether the problem reproduces after restarting; and
- only sanitized error text or the short diagnostic reference shown by the app.

Search existing issues first. One issue should describe one problem. General troubleshooting requests and open-ended feature design belong in Discussions.

## Security vulnerabilities

Do not report suspected vulnerabilities in Discussions or Issues. Follow the private process in [SECURITY.md](SECURITY.md).

## Privacy

Community support cannot safely inspect private databases or files. Reduce problems to synthetic fixtures and remove passwords, tokens, usernames, hosts, source filenames, connection names, row values, and credential-bearing URIs before sharing. See [PRIVACY.md](PRIVACY.md) for the application's data-handling policy.
